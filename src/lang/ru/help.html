AI_Rulet — рулетка идей для проектов с искусственным интеллектом. Нажимаешь «Найти» — и из глубины космоса прилетает задача, которую один-два разработчика могут довести до прототипа: с описанием, стеком технологий и планом первых шагов.

Как пользоваться

  1. Нажми «Найти» или клавишу Пробел / Enter. Около трёх секунд идёт поиск, затем идея встаёт в центр.
  2. Ниже появится карточка идеи — прочитай, подходит ли.
  3. «↻ Найти ещё» — следующая идея, «⧉ Скопировать» — карточка в буфер обмена в формате Markdown, «✧ В созвездие» — сохранить идею.
  4. «⤴ Поделиться» — ссылка на эту идею: на телефоне откроется меню «Поделиться», на компьютере ссылка скопируется. Кто откроет ссылку, увидит ту же карточку.
  5. «Разобрать с ИИ: ↗ Google, ↗ ChatGPT, ↗ Claude» — откроет в новой вкладке выбранный сервис (у Google — режим ИИ на Gemini) с текстом идеи и просьбой оценить её: реалистичность, аналоги, риски, с чего начать. Нужен интернет; режим ИИ в Google доступен не во всех странах, Claude попросит войти в аккаунт.

Что в карточке

Область
направление ИИ, к которому относится идея, и её образное имя.
Стек
инструменты, на которых удобно собрать прототип.
Траектория к прототипу
пять шагов: три — свои для этой идеи, два завершающих — общие для её области.
Аномалия
дополнительное усложнение — для тех, кому основной задачи мало. В каталоге оно своё у идеи или одно из общих для её области.

Откуда берутся идеи

Каталог
заранее составленный набор: в . У каждой идеи — своя траектория, а аномалия — своя или одна из общих для области.
Микс
идея собирается на лету из сферы жизни, техники ИИ, задачи, формата продукта и аномалии — . Сочетаются только совместимые части: технике нужны данные, которые в этой сфере действительно есть, а формат и аномалия подбираются под эти данные. Карточка «Микса» — абзац с форматом и аномалией, без траектории.

Без повторов

В «Каталоге» идеи выпадают как карты из колоды: каждая — один раз, пока круг не пройден. Потом колода собирается заново и не начинает с последней выпавшей идеи. В «Миксе» колоды нет, но сфера и техника не повторяют предыдущий бросок.

Где хранятся данные

Приложение — один файл: работает без интернета и само ничего никуда не отправляет. Текст идеи уходит во внешний сервис, только когда ты сам нажимаешь одну из ссылок «Разобрать с ИИ»; ссылка «Поделиться» содержит лишь короткий код идеи. Хроника, созвездие, пройденная часть колоды и настройки хранятся только в этом браузере — общие для всех языковых версий. Если очистить данные сайта или открыть файл в другом браузере, всё начнётся с чистого листа.

Фон — живой космос: звёзды, туманности, планеты и созвездия с именами из мира ИИ. Пока читаешь карточку, он приглушается, чтобы не отвлекать.
